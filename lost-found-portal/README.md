# Foundly — Campus Lost & Found

A React-only campus lost and found portal for a Full Stack Development class.

## Features

- Home dashboard with recent reports and statistics
- Browse lost/found items
- Search and filter by category/location
- Report lost or found items
- Image preview stored in the browser
- Item details page
- Simple weighted matching algorithm
- Claim request interaction
- My Reports page
- Demo admin dashboard
- localStorage persistence
- Responsive layout

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Important

There is no backend, authentication, or database in this version. Data is stored in the browser using localStorage, so it is intended for a frontend/FSD classroom demonstration.

To reset the sample data, use the "Reset demo data" button on the Admin page.
